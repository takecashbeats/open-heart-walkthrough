# Open Heart Walkthrough

An interactive, start-to-finish guide to coronary artery bypass grafting (CABG), the most common open-heart operation.

- 14 phases, from work-up through anesthesia, sternotomy, cardiopulmonary bypass, grafting, weaning, closure and ICU recovery
- Each phase has ordered steps, who does them, key numbers and what to watch for
- A live monitor strip whose ECG and vitals follow the phase (flat while the heart is arrested)

## Run it

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## About the chat bot

The "Ask the surgical bot" panel uses Claude's artifact runtime, so it only answers when the page is opened on claude.ai. On GitHub Pages or a local file, the phase guide works fully and the chat shows a notice instead.

## Disclaimer

For learning only. Figures are typical textbook ranges and vary by institution and patient. This is not surgical training or medical advice.
